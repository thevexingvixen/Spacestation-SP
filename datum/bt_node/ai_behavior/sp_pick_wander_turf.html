sp_pick_wander_turf
/datum/bt_node/ai_behavior/sp_pick_wander_turf

Picks a random walkable turf inside one of a set of areas and stores it in target_key. Areas come from the blackboard list in areas_key, else from fixed_areas, else from the type of BB_SP_HOME_AREA (including subtypes).

Vars

areas_keyBlackboard key holding a list of /area typepaths to choose from. Optional.
attemptsHow many random turfs to test before giving up on an area.
fixed_areasFixed list of /area typepaths, used when areas_key yields nothing. Optional.
shuffle_areasTry the areas in random order. FALSE tries them in the order listed, first choice first.
target_keyBlackboard key to write the chosen turf into.
