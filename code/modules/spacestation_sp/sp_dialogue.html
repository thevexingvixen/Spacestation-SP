/tg/ Station 13 - Modules - Types

code/modules/spacestation_sp/sp_dialogue.dm

/datum/sp_dialogueWritten dialogue: conversations kept as data rather than as string lists in code.
/datum/sp_dialogue_threadA dialogue somebody is in the middle of.
/proc/sp_in_any_threadWhether somebody is in a conversation with anybody right now.
/proc/sp_all_dialoguesEvery dialogue we ship, read once.
/proc/sp_read_dialogueReads one dialogue file and checks it over, returning it, or null with what was wrong in problems.
/proc/sp_dialogue_check_nodeOne node's worth of checks for sp_read_dialogue().
/proc/sp_dialogue_pair_okWhether "a->b" names two of the dialogue's roles.
/proc/sp_dialogue_unreachableNodes nothing leads to. A node nobody can reach is a line nobody will ever hear.
/proc/sp_dialogue_exitsEverywhere a node can lead: its edges, its replies, and where silence takes it.
/proc/sp_dialogue_placeholdersThe %PLACEHOLDERS% in a line.
/proc/sp_dialogue_placeholder_knownThe area, the event a rumour is about, and each role's first name, full name or job.
/proc/sp_dialogue_compare"value against requirement": ">=4", "<2", "=3", or a bare number meaning equal to it.
/proc/sp_dialogue_is_playerA player, for dialogue: anybody the SP crew controller is not running.
/proc/sp_is_playingSomebody a player is playing: a connected client, or the stand-in that takes one's place in a test.
/proc/sp_dialogue_player_roleThe role the player plays in a thread, if one does.
/proc/sp_in_departmentsWhether somebody holds a job in any of these departments, by the names a file uses.
/proc/sp_dialogue_role_fitsWhether somebody can play a role: the right kind of person (player or crew), in the right job or department.
/proc/sp_cast_dialogueBinds a dialogue's two roles to two people, or null when it does not fit them. Either of them can be the one who walked over: a janitor stopping a clown is the same conversation as a clown stopping a janitor.
/proc/sp_begin_dialogueA thread for these two, not yet started: cast, and with the dialogue's own start conditions holding. Null when it does not fit them. The first line is said on the next tick rather than this one.
/proc/sp_dialogue_had_latelyWhether either of two people has had this one with the other lately.
/proc/sp_pick_dialogueA dialogue these two could have now, or null. trigger picks the ones that start on it (a player's intent, or "newcomer"); with none, it picks from the idle crew-to-crew ones, the ones nothing in particular starts.
/proc/sp_dialogues_for_talkWhat a crew member will talk to this player about, by title: the Talk to list.
/proc/sp_start_threadStarts a conversation run by controller, which is the starter's, and tells the partner they are in it.
/proc/sp_end_dialogueEnds a thread, whatever brought it to an end, and lets everybody in it go.
/proc/sp_memory_keyThe key memory is filed under: a player's mind, so a new body does not reset them; a crew member's name.
/proc/sp_memory_ofWhat a crew member remembers of somebody, made on first use. The entry is held by reference on the blackboard, so changing it changes the memory; only the book itself has to be written with override.
/proc/sp_memory_recentDialogue ids had with somebody lately, newest last.
/proc/sp_knows_nameWhether a crew member knows somebody's name. The crew know each other; a player they learn by being told, or by standing close enough to read the card on their chest (sp_notice_id()).
/proc/sp_notice_idReading somebody's ID from beside them, which is how a stranger's name gets learned without asking.
/proc/sp_dialogue_rememberRemembers that a thread happened, with whom, so the same one is not had again straight away.
/proc/sp_station_eventSomething that happened, for the station to talk about afterwards. Forgotten after SP_EVENT_MEMORY.
/proc/sp_recent_eventThe newest event whose tag starts with tag, within the last minutes, or null.
/proc/sp_dialogue_pair"a->b" as a list of the first one and the second one, or null if either is missing.
/proc/sp_dialogue_hurtHurt enough to show it: below seven tenths of their health, or carrying a wound.
/proc/sp_dialogue_place_matchesWhether the conversation is happening in one of these places, going by where the first of the cast stands.
/proc/sp_dialogue_conditions_holdThe closed vocabulary a file can ask about. See GLOB.sp_dialogue_conditions.
/proc/sp_dialogue_effectThe closed list of what a line can change. See GLOB.sp_dialogue_effects.
/proc/sp_dialogue_giveHands over something the giver actually carries. Nothing is conjured: no item, no gift, just the line.
/proc/sp_dialogue_event_phraseWhat a station event was, in words, for a rumour to say.
/proc/sp_dialogue_strangerWhat a crew member calls somebody whose name they do not know. Security are officious about it.
/proc/sp_dialogue_fillFills a line in. A name the speaker does not know comes out as whatever they call a stranger.
/proc/sp_dialogue_otherWhoever is not the speaker.
/proc/sp_dialogue_still_talkingEverybody in it is alive, awake, near enough, and has nothing more pressing on. Work that turns up, or somebody going for one of them, ends a conversation: none of this outranks the job or an emergency.
/proc/sp_dialogue_notice_idsCrew in a conversation with a player read their ID if they are close enough to.
/proc/sp_dialogue_nextThe next node, by weight, ignoring any edge whose conditions do not hold.
/proc/sp_dialogue_offer_htmlThe replies on offer as the links a player's chat shows under the line they answer. Kept apart from sending them so the stand-in reads exactly what a client would be sent (sp_stand_in.dm).
/proc/sp_talk_offerWhat a crew member will talk to a player about just now, by title; null when they will not talk at all.
/proc/sp_talk_startStarts the conversation a player picked from Talk to, if it is still on offer and they are still close.
