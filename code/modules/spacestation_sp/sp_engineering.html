/tg/ Station 13 - Modules - Types

code/modules/spacestation_sp/sp_engineering.dm

/proc/sp_station_power_needs_workEngineering helpers: power monitoring, a scripted supermatter startup that an AI engineer performs once physically in the engine room, and a watchdog that shuts the emitters off if the crystal degrades.
/proc/sp_in_engine_areaIs this machine inside one of the supermatter engine areas?
/proc/sp_is_loop_pumpPump names (substrings) that belong to the coolant loop and should run at full pressure.
/proc/sp_run_engine_setupSets up the coolant loop and the power infrastructure on behalf of engineer. Returns a one-line spoken summary. Safe to call repeatedly.
/proc/sp_engine_chamber_airGas mixture on the crystal's tile, or null.
/proc/sp_engine_chamber_scrubbersScrubbers inside the crystal chamber.
/proc/sp_nitrogen_fractionNitrogen fraction of a gas mixture (0..1).
/proc/sp_engine_enable_circulationPhase B: once the chamber is full of nitrogen, switch the chamber scrubbers to siphon so the gas circulates through the filters and freezers. Returns TRUE if circulation is (now) on.
/proc/sp_engine_disable_circulationAnti-vacuum guard: if the chamber is being emptied, stop siphoning until it refills.
/proc/sp_engine_chamber_readyTRUE when the chamber holds plenty of cold, circulating nitrogen so the emitters are safe.
/proc/sp_start_emittersTurns on up to max_emitters welded, powered emitters in the engine areas, but only when the chamber is ready and the watchdog has not scrammed the engine. Returns a spoken summary, or null if nothing happened.
/proc/sp_station_smes_chargeTotal charge (joules) across station SMES units.
/proc/sp_feed_smesSplits joules of simulated engine output across the station SMES units (engine room units first).
/proc/sp_scram_engineTurns off every emitter in the engine areas. Used by the watchdog.
