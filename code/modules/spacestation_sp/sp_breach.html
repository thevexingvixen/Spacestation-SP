/tg/ Station 13 - Modules - Types

code/modules/spacestation_sp/sp_breach.dm

/proc/sp_breach_scan_areasBuilds (once) the list of station areas the breach scanner walks.
/proc/sp_is_breach_turfTRUE if this space turf looks like a hole in the hull rather than open space by design.
/proc/sp_breach_standpointA safe, walkable, pressurised-side turf an engineer can stand on to patch breach. Null if there is none.
/proc/sp_find_nearest_breachNearest known breach to who on the same z-level that still needs patching, or null.
/proc/sp_open_internalsPuts a breath mask on and opens an emergency tank, so working next to vacuum is survivable. Best effort: returns TRUE if we are breathing from a tank afterwards.
/proc/sp_close_internalsStops breathing from the tank once the job is done, so it is still full next time.
/proc/sp_patch_breachFires the RCD at breach to lay plating over it. Returns TRUE if the hole is gone afterwards. The RCD must already be in the engineer's active hand.
/proc/sp_patch_breach_clusterPatches breach and then every other hole still within reach, so a five-tile hull rupture is sealed in one visit instead of one full plan-and-walk cycle per tile. Returns how many turfs were sealed.
/proc/sp_debug_make_breachDebug helper: punches count holes in a random pressurised station room. Used by SP_DEBUG_BREACH_COUNT.
